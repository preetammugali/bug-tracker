 🐛 Bug Tracker

A web-based **Bug Tracking System** designed to help administrators and testers manage, track, and resolve software bugs efficiently.

📌 About the Project

The Bug Tracker provides a centralized platform where bugs can be reported, managed, assigned, and tracked through their resolution process.

Th  *Admin* manages the reported bugs and makes them available to testers/developers, while testers can view the bug details, work on them, update their status, and submit the resolution through the system.

✨ Features

- 🔐 User authentication
- 👨‍💼 Admin bug management
- 🐛 Create and manage bugs
- 🔎 Search and filter bugs
- 📋 View complete bug details
- 📊 Track bug status
- 👨‍💻 Tester/developer bug resolution
- 🔄 Update bug status
- 🗄️ Database storage using Supabase
- 🌐 Web-based frontend
- ⚡ FastAPI backend
- 📱 Responsive interface
